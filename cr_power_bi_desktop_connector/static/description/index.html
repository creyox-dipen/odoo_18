  What is the Odoo to Power BI Desktop Connector?

The Desktop Connector allows you to push Odoo data directly into Power BI Desktop, enabling advanced analytics and visualization without manual data exports.

  What is Microsoft Fabric Services, and how does it integrate with Odoo?

Microsoft Fabric is a full-stack analytics platform that supports Eventhouse, KQL databases, and workspaces. Through Odoo, users can create, fetch, and manage these Fabric services for real-time data analysis and visualization.

  Which licenses are required for different features?

Pro licenses are sufficient for creating reports, dashboards, Eventhouse, and KQL databases. Deployment pipelines require Premium or Premium Per User (PPU) licenses.

  How does the deployment pipeline work?

Deployment pipelines allow you to move workspaces, reports, and dashboards across Development, Test, and Production stages in a controlled, automated way. It ensures each workspace is linked to a single stage and pipeline for consistency.

  Can multiple workspaces be managed within Odoo?

Yes, you can manage multiple workspaces directly within Odoo, including creating, fetching multiple eventhouses and databases within workspaces.

  Is this app compatible with Odoo Community as well as Enterprise?

Yes, this app works perfectly with Odoo Enterprise (Odoo.sh & On-Premise) as well as Community.

  Is this app compatible with Odoo Online?

No, this app will not work for Odoo Online.
