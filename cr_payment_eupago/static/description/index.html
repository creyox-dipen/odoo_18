  • Navigate to Invoicing >> Configuration >> Payment Providers.
  • There, you will find the three eupago payment providers.
  • There, click on euPago - Multibanco (ATM Reference) payment Provider.
  • Now, in the euPago dashboard, navigate to Management >> Channels >> Channel Listing, then copy the API Key from the required channel.
  • Click Edit to configure additional settings for the channel in the euPago dashboard.
  • Enable Receive notification of referrals by email, select the Type of Email options as shown in the image below, and provide an email address to receive transaction notifications.
  • Enable Receive notification for a URL and enter the webhook URL in the URL field using the following format: https://<your-odoo-domain>/payment/cr_eupago/webhook.
  • Open the Multibanco payment provider, enable it, and paste the copied API key into the euPago API Key field.
  • Configure the Multibanco Deadline (Days), Minimum Amount, and Maximum Amount according to your business requirements.
  • In the Configuration tab of the payment provider, ensure that the Multibanco payment method is enabled and the Euro (EUR) currency is set.
  • Now, Click on the Extra Fees tab to configure the payment fee settings.
  • Enable Add Extra Fees to automatically calculate and add payment processing fees to the order during checkout.
  • Fees Product will be used to create the additional fee line on the sales order or invoice.
  • Configure separate Domestic Fees and International Fees by specifying both Fixed Fees and Variable Fees (in percent).
  • Enable Free Domestic Fees if Amount is Above and specify the amount limit. If the order total exceeds this limit, no domestic fees will be charged.
  • Enable Free International Fees if Amount is Above and specify the International Total Amount. If the order total exceeds this limit, no international fees will be charged.
  • If the customer's delivery address country matches the company's country, the configured Domestic Fees will be applied. Otherwise, the configured International Fees will be applied.
  • Whenever the customer proceeds to the checkout page, the configured payment fees will be calculated automatically and added as a separate fee line.
  • Example: Variable Domestic Fees = 2%, Fixed Domestic Fees = €0.30, Order Amount = €320.00
  • Variable Fee = 2% of €320.00 = €6.40
  • Total Fee = €6.40 + €0.30 = €6.70
  • If Free Domestic Fees if Amount is Above is enabled and the threshold is set to €300.00, no fee will be charged because the order amount (€320.00) exceeds the configured limit.
  • Similarly, configure the euPago — MB WAY payment provider by enabling it and pasting the API Key copied from the euPago dashboard. Set the Minimum Amount, and Maximum Amount as required.
  • Also paste the Client ID and Client Secret copied from the euPago dashboard. These credentials are required to process MB WAY refunds.
  • To obtain the Client ID and Client Secret, log in to the euPago dashboard and click the Profile icon in the top-right corner and click on My Account.
  • Open the Credentials tab, click the + Create Credentials button, and create a new set of credentials. Copy the generated Client ID and Client Secret, then paste them into the corresponding fields in the Odoo payment provider form.
  • You can also enable and configure the Extra Fees for the MB WAY payment provider from the Extra Fees tab, following the same configuration steps as described for the Multibanco payment provider.
  • Now, configure the euPago — Credit Card payment provider by enabling it and pasting the API Key, Client Id and Client Secret copied from the euPago dashboard. Set the Minimum Amount, and Maximum Amount as required.
  • In the Configuration tab of the payment provider, ensure that the Card payment method is enabled and the Euro (EUR) currency is set.
  • Configure the payment fees from the Extra Fees tab by following the same steps described previously.
  • On the checkout page, you will see three payment methods. Selecting Card payment method the Fees Badge will be visible, which displays the fee calculated based on the configured settings. Then, click Pay Now to proceed with the payment.
  • You will be redirected to the euPago Card Payment hosted page. Enter the card details and complete the payment.
  • On the next page, enter the OTP received on your registered mobile number and proceed with the payment.
  • After the payment is successfully completed, you will be redirected back to Odoo, where you can verify that the payment has been processed successfully.
  • On the order and invoice, you will see a dedicated Fee line automatically added after the payment is completed, and the corresponding invoice will be automatically marked as Paid.
  • If the payment was made using the euPago Credit Card payment method, a Refund via euPago button will be available on the invoice. Click this button to initiate either a full or partial refund.
  • Clicking the Refund via euPago button will open a pop-up displaying the full refundable amount. Modify the amount if you want to issue a partial refund, then click Confirm Refund to proceed.
  • After the refund is processed successfully, the corresponding Credit Note will be automatically created and reconciled.
  • Similarly Card Payment, You can pay invoice directly from the backend, on invoice form click on Preview button.
  • Click the Pay Now button, selecting MB WAY payment method fees badge will be visible, enter your mobile number, and click Pay.
  • A payment request will be sent to the provided mobile number. Open the MB WAY app and confirm the payment request to complete the transaction.
  • After confirming the payment in the MB WAY app, the transaction will be processed successfully, and the corresponding invoice will be automatically marked as Paid.
  • You can also refund payments made using the MB WAY payment method by clicking the Refund via euPago button, following the same steps as described for the Card payment method.
  • To pay using Multibanco, select the Multibanco payment method on the checkout page or invoice payment portal, Selecting it fees badge will visible, then click the Pay button.
  • The payment request will be created and remain pending until it is approved. Once the payment is approved, the transaction will be completed successfully, and the corresponding invoice will be automatically marked as Paid.

Which payment methods are supported?

This module supports 3 core payment methods offered by euPago in Portugal: Multibanco (ATM references), MB WAY, and standard Credit Cards.

Does this module auto-reconcile transactions?

Yes! Because it is built on Odoo's standard Payment Provider framework, successful payments are automatically reconciled with their corresponding invoices without manual intervention.

Do I need an existing euPago account?

Yes, you must have an active euPago account. You only need your API Key from your euPago dashboard to configure and authenticate this module in Odoo.

Is the checkout process secure and compliant?

Absolutely. All payment processing is securely handled via the euPago API, which is fully compliant with PSD2 regulations and supports 3D Secure for credit card transactions.

Is this app compatible with Odoo Online?

No, this app will not work for Odoo Online.
