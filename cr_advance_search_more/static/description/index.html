How It Works in Action

Explore how each intelligent search capability accelerates your daily Odoo operations with interactive visual demonstrations.

01 • Search Modes Default | OR | AND | NOT

Dynamic Multi-Keyword Search Modes

Switch search logic on the fly right beside the search bar. The engine splits multi-word phrases into distinct keywords and applies the selected logical operator across standard fields as well as relational fields (Many2one, Many2many, One2many).

  • Default Mode: Searches using standard Odoo search logic.
  • OR Mode: Matches records containing any of the typed keywords.
  • AND Mode: Requires every keyword to be present in the record.
  • NOT Mode: Instantly excludes records matching the specified keywords.
Real-World Example with Desk Chair:
  • OR Finds all records containing either "Desk" or "Chair" (or both).
  • AND Finds only records that contain both "Desk" and "Chair".
  • NOT Finds all records while excluding any that match "Desk" or "Chair".
02 • Search History Up to 15 per Model

Recent Search History

Never type repetitive search queries again. The system automatically records up to 15 recent search terms per model in Odoo, enabling immediate 1-click re-execution with the exact search mode preserved.

  • Instant Recall: Re-run any past search keyword with a single click.
  • Mode Preservation: Automatically remembers the active search mode used.
  • Item Control: Delete specific items by () or clear history completely.
Real-World Example:

If you frequently search for Deco Addict or Ready Mat, simply click the History icon in the search bar to execute the search in 1 click.

03 • Custom Filters Inline Rename & Delete

Saved Custom Filter Presets

Bookmark complex, multi-criteria filter domains (up to 15 per model) for quick access across any list and kanban view. Rename filter presets directly from the dropdown to keep your workflows intuitive and well-organized.

  • Store Presets: Saves active multi-clause filters and search domains automatically.
  • Pencil Rename: Click the pencil () icon to edit filter labels anytime.
  • Cross Delete: Click the cross () icon to remove filter presets.
Real-World Example:

Create a filter for Total > $10,000 & Status = Sale, rename it to "VIP High-Value Deals", and re-apply it with one click anytime.

04 • Custom Group By

Saved Custom Group By

Stores your custom Group By history (up to 15 per model) to quickly group and organize records with a single click.

  • Group By History: Stores your custom Group By history (up to 15 per model).
  • Pencil Rename: Click the pencil () icon to customize grouping names.
  • Cross Delete: Click the cross () icon to remove saved groupings.
Real-World Example:

Save a custom group by like Product Category in Products named "Category Wise" to group records in 1 click anytime.

05 • List View Search Real-Time & Highlights

Inline Column Header Search & Reset

Filter table records directly underneath list headers with field-tailored search inputs. Matched search terms are highlighted with glowing high-contrast tags, and all column filters can be cleared in one click.

  • Field Inputs: Text, date ranges (From/To), selection, and boolean selectors.
  • Keyword Highlighting: Automatically highlights matching text across list rows.
  • 1-Click Reset: Click on the top-left header to clear all column inputs.
Real-World Example:

On the Sales list view, set From Date and To Date under Order Date to filter sales orders between specific dates instantly.

What is Smart Advanced Search Engine?

It is an advanced search enhancement module for Odoo that adds multi-keyword search modes (Default, OR, AND, NOT), inline column header filtering in list view, search keyword glowing highlights, recent search history memory, and quick filter access popups.

How do the Search Modes (Default, OR, AND, NOT) work?

Simply pick a mode from the search bar dropdown. Default uses standard Odoo behavior; OR matches records containing any of the typed words; AND requires all words to match; and NOT excludes records containing those words.

Which field types are supported in Inline Column Search?

It supports text fields (Char, Text, Selection, Many2one, Integer, Float), dual date ranges (From / To date inputs), and boolean fields via a clean Yes / No dropdown.

Does search keyword highlighting work in Kanban view?

Yes! Search term highlighting automatically highlights matched text across both List view table cells and Kanban view cards with glowing high-contrast background tags.

Is this app compatible with Odoo Community & Enterprise?

Yes, this module works seamlessly with Odoo Enterprise (Odoo.sh & On-Premise) as well as Odoo Community edition.

Is this app compatible with Odoo Online (SaaS)?

No, custom Odoo apps that patch Web Client assets require Odoo.sh, On-Premise, or self-hosted deployment, and are not supported on Odoo Online (SaaS).
