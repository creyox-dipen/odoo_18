What is Dynamic Report Studio?

It is a visual document design module for Odoo that replaces coding PDF layouts in HTML and QWeb XML. It provides a drag and drop workspace where users can build invoices, purchase orders, shipping labels, and custom business reports in minutes.

Does it support dynamic fields and data tables?

Yes. You can drag and drop individual dynamic fields using Python expressions and add dynamic data tables that automatically loop through and display line items in real time.

Can I use barcodes and QR codes in my reports?

Yes. The module features a built in barcode and QR code generator that can be linked to dynamic Odoo database fields such as product barcodes or order tracking IDs.

Does this module support multi page document design?

Yes. The builder includes a page break component to control layout flow and supports multi page watermark syncing to repeat logos or headers across all pages automatically.

Is this app compatible with Odoo Community as well as Enterprise?

Yes, this app works perfectly with Odoo Enterprise (Odoo.sh & On Premise) as well as Community.

Is this app compatible with Odoo Online?

No, this app will not work for Odoo Online.
